# Mom's Canning Timer Customization

Mom's Canning Timer is customizable directly from the GUI — no code editing
required.

## Change Timer Length

Each of the four burners has a **Min** spinbox. Set it to the number of minutes
you want (1–180), then press **Start**. The timer counts down from that
duration and the ring around it sweeps to show progress.

You can give each burner a different length, so you can can several items with
different processing times at once.

## Controls

Each burner has:

- **Start** — read the spinbox value and begin the countdown.
- **Pause / Resume** — toggle a running timer; the button label switches between
  `Pause` and `Resume`.
- **Reset** — stop the timer and restore it to its full duration.

When a timer reaches zero, the ring turns red, the bell rings, and a popup tells
you which burner is done.
